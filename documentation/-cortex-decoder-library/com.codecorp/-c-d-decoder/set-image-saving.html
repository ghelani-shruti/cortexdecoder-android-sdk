setImageSaving

public void setImageSaving(CDDecoder.CDImageSaving saveImageType)

setImageSaving provides a way to save camera frames in app sandbox. Images are saved in PNG format. Default setting is disable. 

Sample usage
//Do not save image
CDDecoder.shared.setImageSaving(CDImageSaving.disable);
//Save first image
CDDecoder.shared.setImageSaving(CDImageSaving.first);
//Save first decoded image with decode data containing the user specified string
CDDecoder.shared.setImageSaving(CDImageSaving.firstDecoded);
