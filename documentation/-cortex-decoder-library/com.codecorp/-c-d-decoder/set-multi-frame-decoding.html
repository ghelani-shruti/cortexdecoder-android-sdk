setMultiFrameDecoding

public void setMultiFrameDecoding(boolean enable, CDMultiFrameDecodeCountListener cdMultiFrameDecodeCountListener)

setMultiFrameDecoding enables Multi Scanning functionality in CortexDecoder.

Note: This allows the application to scan multiple barcodes using multiple frames. CortexDecoder will only decode unique barcode data. CortexDecoder returns the data when it decodes all unique barcodes.

After you enable this mode, you need to disable exactlyNBarcodes by passing false and set the number of barcodes that has to be scanned by using setBarcodesToDecode. 
Sample usage
//if you want to scan 4 barcodes.
CDDecoder.shared.setNumberOfBarcodesToDecode(4, false);
// enable multi frame and pass a count listener
CDDecoder.shared.setMultiFrameDecoding(true, count -> {
    Toast.makeText(this,"onMultiFrameDecodeCount: "+String.valueOf(count), Toast.LENGTH_SHORT).show();
});
