setDPM

public void setDPM(CDPerformanceFeatures.CDDPM dpmType)

setDPM enables the CDDPM type. Only 1 type can be enabled at a time, so when switching between different types CortexDecoder will disable the earlier one. Defaults to disable. 

Sample usage
//disable
CDPerformanceFeatures.shared.setDPM(CDPerformanceFeatures.CDDPM.disable);
//dotPeenDarkOnLight
CDPerformanceFeatures.shared.setDPM(CDPerformanceFeatures.CDDPM.dotPeenDarkOnLight);
//dotPeenLightOnDark
CDPerformanceFeatures.shared.setDPM(CDPerformanceFeatures.CDDPM.dotPeenLightOnDark);
//dotpeenAndEtch
CDPerformanceFeatures.shared.setDPM(CDPerformanceFeatures.CDDPM.dotpeenAndEtch);
//laserChemEtch
CDPerformanceFeatures.shared.setDPM(CDPerformanceFeatures.CDDPM.laserChemEtch);
