CDResult

public class CDResult implements Serializable

CDResult class is used to store and return barcode data back to the customer.

CortexDecoder returns barcode data via different callback listeners for different use cases.

  • Camera scanning - CDCameraDecodeListener.
  • Image scanning - CDImageDecodeListener.
CortexDecoder always returns an array of CDResult (this supports multiple barcodes). The followings are fields supported in CDResult along with their data type.

CDResult class provides details about barcode data, symbology, barcode coordinate with respect to camera preview, decode time, etc. It also has the status field which informs of either a successful barcode decode or error code for the each frame it received/processed using the following possible values: success, noDecode, noActiveLicense, decodingDisabled, noUniqueDecode, etc. CDResult also contains barcode verification and codewords information when these particular features are enabled.
