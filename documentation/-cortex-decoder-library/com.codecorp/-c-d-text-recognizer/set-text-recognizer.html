setTextRecognizer

public void setTextRecognizer(@NonNull() String format, @NonNull() CDTextRecognizerListener cdTextRecognizerListener)

API used to control text recognition.

Note: Text Recognition will be disabled after each successful decode and will need to be called again for next scan. If the use case is a continuous scan, then setting a recursive call will be one way to achieve it. To disable text recognition, simply pass anything other than supported formats to param format. To enable one of the supported formats must be passed, API getSupportedFormats can be used to retrieve supported formats. 

Sample usage
// enable
CDTextRecognizer.shared.setTextRecognizer("MRZ", this::onTextRecognition);
// disable
CDTextRecognizer.shared.setTextRecognizer("", this::onTextRecognition);
