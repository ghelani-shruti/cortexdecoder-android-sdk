setResolution

public void setResolution(CDCamera.CDResolution resolution)

setResolution sets the desired resolution. Defaults to resolution 1280x720. 

Sample usage
//resolution - `CDCamera.CDResolution` constant used to set camera resolution type.

// setting resolution to 640x360.
CDCamera.shared.setResolution(CDResolution.res640x360);

// setting resolution to 1280x720.
CDCamera.shared.setResolution(CDResolution.res1280x720);

// setting resolution to 1920x1080.
CDCamera.shared.setResolution(CDResolution.res1920x1080);

// setting resolution to 3840x2160.
CDCamera.shared.setResolution(CDResolution.res3840x2160);
