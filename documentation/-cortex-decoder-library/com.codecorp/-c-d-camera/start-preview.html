startPreview

public View startPreview()

startPreview starts the camera preview if not already started and returns the View object that will display the live preview images from the camera. If camera is not running, an empty View will be returned which will update later when camera starts. 

Sample usage
// Start Preview
 View mPreview = CDCamera.shared.startPreview();
 // Update RelativeLayout with Camera Preview
 RelativeLayout mCameraFrame = (RelativeLayout)(findViewById(R.id.activity_scan_frame));
 // add mPreview at index 0
 mCameraFrame.addView(mPreview, 0);
