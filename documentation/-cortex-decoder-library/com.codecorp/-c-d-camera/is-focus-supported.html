isFocusSupported

public boolean isFocusSupported(CDCamera.CDFocus focus)

isFocusSupported checks if device supports all CDFocus types supported by CortexDecoder. It returns a Boolean value. 

Sample usage
//focus - CDCamera.CDFocus constant to check if the device supports focus.
boolean isFocusSupported = CDCamera.shared.isFocusSupported(CDFocus.fixed);
