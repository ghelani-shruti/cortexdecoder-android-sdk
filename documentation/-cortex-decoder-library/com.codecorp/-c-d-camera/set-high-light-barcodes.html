setHighLightBarcodes

public void setHighLightBarcodes(boolean enable)

setHighlightBarcodes enables highlights for decoded barcodes. It draws a red or green boundary box on all barcodes that are decoded in each frame. SDK will clear barcode highlight as soon as it receives the next frame. 

Sample usage
//enable
 CDCamera.shared.setHighLightBarcodes(true);
 // disable
 CDCamera.shared.setHighLightBarcodes(false);

public void setHighLightBarcodes(boolean enable, int color)

setHighLightBarcodes Enables highlights for decoded barcodes with desired color. Draws a boundary box of provided color on all barcodes that are decoded in each frame. SDK will clear barcode highlight as soon as it receives next frame. 

Sample usage

// Color's int value can be retrieved in following ways
 int desiredColor = Color.RED;
 int desiredColorWithARGB = Color.argb(150, 255, 0, 0);
 int desiredColorWithHexString = Color.parseColor("#FF0000");

// How to call the api
 CDCamera.setHighLightBarcodes(true, desiredColor);
