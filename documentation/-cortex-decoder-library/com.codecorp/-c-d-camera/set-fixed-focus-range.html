setFixedFocusRange

public void setFixedFocusRange(float range)

setFixedFocusRange allows to change fixed focus distance when fixed focus mode is enabled. 

Sample usage
//range - sets the focus distance. Make sure float value passed is between getSupportedFixedFocusRange()[].
CDCamera.shared.setFixedFocusRange(1.0f);
